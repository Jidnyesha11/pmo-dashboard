# ClickUp Setup Guide

Create a **Space** named AI Support Platform, a **Folder** named Delivery, and Lists: Governance, Product Backlog, Engineering, Quality & UAT, Release & Hypercare. Configure statuses Open, In Progress, Blocked, In Review, Complete. Use priority values Urgent/High/Normal/Low, and task types Epic, Story, Task, Milestone, Bug.

Import `ClickUp_Task_Import.csv` into the matching List via CSV import. Map Task Name, Task ID, Description/workstream, Assignee, Start Date, Due Date, Status, Priority, Parent ID, Sprint, Completion, and Dependency IDs. Confirm dependencies after import and assign team members from the roster. Treat IDs as source references.

Create a Timeline view grouped by workstream with start/due date and dependency fields; a Workload view grouped by assignee with capacity set to 40 hours/week; a Board view grouped by status; and a Calendar for milestones. Use the dashboard as the baseline for forecasts, then document any approved changes. No ClickUp workspace is connected by this repository.
