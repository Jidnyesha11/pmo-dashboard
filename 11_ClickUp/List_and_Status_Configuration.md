# ClickUp Lists and Statuses

| List                | Suggested content                                     | Default owner    |
| ------------------- | ----------------------------------------------------- | ---------------- |
| Governance          | Charter, decision and change-control tasks            | Project Manager  |
| Product Backlog     | Epics and user stories                                | Product Manager  |
| Engineering         | API, access, ingestion, RAG, UI and integration tasks | Engineering Lead |
| Quality & UAT       | Test strategy, security, regression and UAT           | QA Lead          |
| Release & Hypercare | Training, go-live, monitoring and closure             | Project Manager  |

Statuses: Open (not started), In Progress (active), Blocked (dependency/input), In Review (acceptance review), Complete (accepted). Keep risk and issue records in dedicated register lists if ClickUp is used operationally; a task status does not replace risk treatment tracking.
