# Dashboard Page Specification

## 1. Executive Overview

Cards: overall status, task progress, schedule, budget, variance, sprint, open/critical risks and overdue work. Trend visuals: cumulative planned/actual spend, completion by workstream, sprint points, milestone status. Tables: attention items and decisions. Slicers: reporting date and workstream.

## 2. Project Timeline

Task matrix with WBS, name, owner, baseline/forecast start and finish, completion, status and predecessor. Gantt custom visual or stacked bar implementation; milestone overlay. Drill-through by task ID. Slicers: workstream, owner, priority, status, dates, sprint.

## 3. Risks and Issues

Risk probability-impact matrix, severity distribution, category counts, risk table with mitigation owner/due/status/residual score; separate issue table with severity/priority/resolution. Filter by category, owner, status, review period.

## 4. Resource Management

Team roster, available vs allocated hours, planned utilization, capacity by sprint, over-allocation flags and action list. Filter by workstream and sprint. Label utilization as simulated planning data.

Additional pages: Financials (monthly planned/actual, category baseline, forecast and contingency held separately); Agile (epic/story hierarchy and completed points); AI Quality (simulated numerator/denominator indicators, latency, UAT and defect definitions). Use accessible colors, labels, tooltips, and a persistent simulation note.
