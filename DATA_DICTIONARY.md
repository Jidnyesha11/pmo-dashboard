# Data Dictionary and Relationships

Dates use ISO `YYYY-MM-DD`; month fields use `YYYY-MM`. IDs are stable string keys. Currency is integer INR. Percentages in source records use 0–100 for task completion and ratios are calculated in the dashboard. Empty dependency strings mean no predecessor. The JSON read model is generated alongside the CSV tables from `scripts/generate_data.py`.

| Table / file             | Primary key                         | Important columns                                                                                                           | Relationships                                                                     |
| ------------------------ | ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| project_config.json      | projectId                           | startDate, endDate, reportingDate, budgetBaseline, currency, sprintDurationDays, selectedSprintWindow, category allocations | Shared assumptions                                                                |
| budget_categories.csv    | category                            | budgetBaselineINR, contingencyFlag                                                                                          | Finance dimension; contingency held separately                                    |
| tasks.csv                | taskId                              | WBS, workstream, owner, baseline/forecast dates, status, completionPct, optional storyId                                    | owner → team.name; sprintId → sprints; storyId → stories; predecessor IDs → tasks |
| dependencies.csv         | predecessorTaskId + successorTaskId | type (Finish-to-Start)                                                                                                      | Both task IDs → tasks                                                             |
| milestones.csv           | milestoneId                         | baselineDate, forecastDate, status, owner                                                                                   | owner → team.name                                                                 |
| team.csv                 | resourceId                          | name, role, capacity, allocated/actual hours, hourly cost                                                                   | Resource dimension for task/resource facts                                        |
| resource_allocations.csv | sprintId + resourceId               | availableHours, allocatedHours, actualHours, plannedUtilizationPct                                                          | sprintId → sprints; resourceId → team                                             |
| sprints.csv              | sprintId                            | dates, goal, selected                                                                                                       | Story and burndown parent                                                         |
| epics.csv                | epicId                              | name                                                                                                                        | Parent to stories                                                                 |
| stories.csv              | storyId                             | epicId, points, sprintId, status, acceptanceCriteria                                                                        | epicId → epics; sprintId → sprints                                                |
| burndown.csv             | sprintId + date                     | day, remainingPoints                                                                                                        | sprintId → sprints                                                                |
| risks.csv                | riskId                              | probability, impact, score, severity, mitigation, residualRisk                                                              | owner → team member                                                               |
| issues.csv               | issueId                             | severity, priority, status, dueDate, resolutionPlan                                                                         | owner → team member                                                               |
| stakeholders.csv         | stakeholderId                       | power, interest, cadence, strategy                                                                                          | Stakeholder dimension                                                             |
| raci.csv                 | deliverable                         | Accountable, Responsible, Consulted, Informed                                                                               | Roles/stakeholders                                                                |
| costs.csv                | period + category                   | plannedCostINR, actualCostINR, commitmentINR                                                                                | Period → Date; category → budget category                                         |
| quality.csv              | observationDate                     | sample size, accurate/grounded/unsupported numerators, latency, UAT, defects, reopened/resolved                             | Date dimension                                                                    |
| status_snapshots.csv     | snapshotDate                        | projectCompletionPct, cumulativeActualCostINR, open risks/issues, status                                                    | Weekly simulated snapshot trend                                                   |
| change_requests.csv      | changeRequestId                     | date, title, impact, status, approver                                                                                       | Change-control register                                                           |
| decisions.csv            | decisionId                          | date, decision, owner, status, rationale                                                                                    | owner → stakeholder/team                                                          |

Risk score = probability × impact (each 1–5). Severity: Low 1–4, Medium 5–9, High 10–15, Critical 16–25. Costs include zero contingency rows so category allocations can be reviewed without counting contingency as actual spend.
